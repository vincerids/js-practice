# Практика по JavaScript

В этом репозитории собраны мои практические задачи по JavaScript. Здесь отрабатываются навыки работы с асинхронностью, запросами к REST API, обработкой ошибок и структурами данных.

## 📌 Что здесь есть:
* **Асинхронность:** Promises, `async/await`, `Promise.all`.
* **Работа с API:** запросы через `fetch` и `axios` к публичным API (CoinGecko, Open-Meteo).
* **Обработка ошибок:** `try/catch`, проверка `response.ok`, обработка сетевых сбоев.
* **Структуры данных:** использование `Map`, `Set` и рекурсии для решения задач.
